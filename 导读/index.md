# 经典教材导读：从初学卡点到核心顿悟

经典计算机科学教材往往是作者数十年功力的浓缩——**它们直接给出了最优雅的终极答案，却常常省略了“当年人们到底被什么烂问题折磨得走投无路，才发明出这个答案”的过程。**

初学者如果缺少那段“受挫与碰壁”的前置体感，直接顺着第 1 页往下啃，很容易陷入**“每个字都认识，但不知道为什么要搞这么复杂”**的眩晕感。

本文件夹专门存放体系内 **10 本经典教材的深度导读**。每篇导读不重复抄书上的目录，而是聚焦解决以下四个问题：

1. **初学者为什么会卡住？**（指出默认思维习惯与书中高阶抽象之间的断层）
2. **必经的心路历程是什么？**（拆解从“直觉崩塌”到“拍案叫绝”的几个关键认知台阶）
3. **怎么用最小代价动手破局？**（提供几十行到百来行代码的“脱敏热身练习”，先攒痛点再看良药）
4. **如何衔接后续的自创进阶课？**（明确书中哪个概念会成为后面系统课或 UI 工程课的基石）
