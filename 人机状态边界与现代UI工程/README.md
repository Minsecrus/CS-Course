# 《人机状态边界与现代 UI/UX 工程》课程总纲

* **课程定位**：人机交互与客户端状态系统工程进阶课
* **前置要求**：具备几千行代码的项目开发经验，学完 `SICP`（函数与数据抽象）、`APOSD`（软件设计的哲学）与 `TAPL`（复合类型基础）核心章节
* **学时配置**：**48\~64 学时（32 学时理论推演 + 16\~32 学时实战工坊）**
* **详细周计划**：请参阅 [《16周教学与实战工坊大纲》](./16周完整教学与对抗工坊大纲.md)

---

## 一、 课程定位与设计理念

本课程把现代 UI/UX 工程放在**异步分布式系统的客户端终点**与**人类视觉、操作习惯的交界处**来研究。

在生成式 AI 已经能够快速生成静态页面代码的背景下，课程把重点放在构建高可靠、高信息密度、操作顺畅的专业软件所需的工程能力上：

1. **信息密度与交互效率**：结合视觉信息密度指标（数据墨水比）与人机工程学规律（费茨定律、希克定律、KLM 击键耗时模型），砍掉冗余装饰，设计适合长时间高频使用的专业软件界面。
2. **响应式状态管理与异步并发控制**：打通从强类型状态机、细粒度响应式更新（Signals）、异步并发控制策略（取消旧请求、串行队列、防重复提交）、分层状态机（Statecharts）到本地优先同步引擎（Local-First Sync Engine）的完整状态管理体系。
3. **逻辑与样式解耦、高性能画布与代码静态约束**：通过无样式逻辑组件（Headless UI）、设计变量（Design Tokens）、Canvas 与 DOM 混合渲染，以及基于语法树（AST）的代码检查与类型约束（UI Harness），保证复杂视图与 AI 生成代码的质量。

## 二、 贯穿全课的三个定量指标

课程中的所有界面改造与实验验收，都依靠以下三个定量指标来衡量：

1. **KLM 击键级耗时模型（衡量操作效率）**
   把用户的每一次操作拆解为基础动作耗时，用加法算出总时间：
   * 按一次键盘（Keystroke）：$K \approx 0.20\text{秒}$
   * 手在键盘和鼠标之间切换一次（Homing）：$H \approx 0.40\text{秒}$
   * 移动鼠标指向目标（Pointing，服从费茨定律）：$P = a + b \log_2\left(\frac{D}{W} + 1\right) \approx 1.10\text{秒}$
   * 视线转移与思考选择（Mental Prep，服从希克定律）：$M = c \log_2(n + 1) \approx 1.20\text{秒}$
2. **数据墨水比（Data-Ink Ratio，衡量信息密度）**
   $$\text{有效信息占比} = \frac{\text{真正展示核心业务数据与状态的像素面积}}{\text{屏幕占用的总像素面积与 DOM 节点数量}}$$
   去掉无意义的装饰卡片、大留白与多余边框，让屏幕上的视觉重点与业务的真实重要程度保持一致。
3. **帧率预算、布局稳定度与回滚准确性（衡量系统稳定性）**
   * 主线程单帧处理时间不超过 $16.6\text{ms}$（$60\text{Hz}$），不因后台数据更新卡死用户的键盘和鼠标输入；
   * 在数据异步加载、网络延迟或流式输出文本时，页面累计布局偏移（CLS）严格为 $0$（页面元素不乱跳）；
   * 采用乐观更新（先更新界面再发请求）时，一旦后端报错，前端状态能够准确回滚到操作前的状态，不留残余错误数据。

## 四、 三项实战考核标准

课程不考概念背诵，而是用自动化测试脚本从三个方面检验学生重构或编写的界面系统：

### 1. 极端数据与弱网自动化测试 (40%)

提交的界面程序会直接接入自动化异常注入测试台：
* **极端数据注入**：自动填入 500 字符无空格长字符串、带组合表情符号的文本、从右向左（RTL）排版的阿拉伯语文本、`0` / `null` / `NaN` 等边界数值、空数组以及 50,000 行大列表，并动态缩放浏览器窗口宽度。
* **弱网与并发干扰**：随机把部分接口延迟拉长到 3 秒，同时让后发出的请求在 50 毫秒内提前返回（制造乱序竞态），随机返回 `502` 报错或模拟断网重连，并模拟快速连续点击与高频流式文本推送。
* **评分标准**：全程不能出现文字重叠、不能把按钮挤出屏幕、页面布局不能乱跳（$\text{CLS} = 0$）、旧请求返回的数据不能覆盖新数据、不能产生重复提交，也不能出现整页白屏崩溃。

### 2. 高密度界面改造与防误触设计 (30%)

给出一个由大模型生成的、外观花哨但操作繁琐的后台界面，要求进行重构：
* **精简节点与提升密度**：保留全部业务功能，**删掉至少 40% 多余的 DOM 节点和装饰元素**，让首屏呈现的有效业务信息量翻倍。
* **缩短操作路径并防止误操作**：
  * 把日常高频操作从“点开菜单 $\rightarrow$ 弹窗 $\rightarrow$ 选择 $\rightarrow$ 保存”的 4 步流程，简化为 **1 步直达动作（KLM 理论耗时减少 70% 以上）**；
  * 普通可逆操作采用“立即生效 + 底部弹出可撤销提示（Undo）”；高风险不可逆操作（如清空数据、全部平仓）采用长按确认或输入名称校验，防止操作员因为习惯性连按回车而引发事故。

### 3. 纯键盘无鼠标操作验收 (30%)

验收时禁用鼠标点击事件，全程只用 `Tab`、`Shift+Tab`、`Enter`、`Space`、`Esc`、方向键和快捷键操作：
* **评分标准**：
  1. 焦点移动顺畅闭合，不会丢失焦点（焦点不能掉回页面空白处），且当前选中的元素始终有清晰的边框高亮；
  2. 打开弹窗或抽屉时，焦点必须锁在弹窗内部；按 `Esc` 关闭后，焦点必须准确回到打开该弹窗的那颗按钮上；
  3. 表格、列表支持方向键快速移动焦点（无需连按上百次 `Tab` 键），并配有 `Cmd+K` 命令面板支持快速跳转与执行命令。
